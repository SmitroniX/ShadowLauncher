Setup & Performance Manual

Installation & RAM Optimization Guide

Comprehensive instructions for installing Shadow Launcher and configuring JVM memory for stutter-free Minecraft Java on mobile.

📥

1. Android Installation

Download ShadowLauncher.apk, tap the notification or file manager, and enable "Install unknown apps" when prompted. Requires Android 8.0+.

📁

2. Scoped Storage Access

Instances are stored safely in Android/data/com.shadowlauncher/files/instances/. Tap the in-app Folder shortcut anytime to open directly in your file manager.

⚡

3. Vulkan vs. HolyGL

Use VulkanMod 1.3 for maximum frame rates and lower thermals on Snapdragon/Mali GPUs. Fall back to Holy GL4ES for legacy 1.8.9/1.12.2 mods.

Device Physical RAM Optimal Shadow Heap Allocation Recommended Target Profile
4 GB Phone 1536 MB – 2048 MB Vanilla 1.20 / Fabric + Sodium (6 Chunks)
6 GB Phone 2560 MB – 3072 MB Fabric + Sodium + Iris Shaders (8 Chunks)
8 GB Phone 3584 MB – 4096 MB Heavy Modpacks (ATM9, Prominence II, 10–12 Chunks)
12 GB+ Phone / Tablet 4608 MB – 5120 MB Ultra Shaders (Complementary Reimagined, 16 Chunks)
⚠️ RAM Allocation Tip: Avoid allocating 100% of your device RAM to Java. Android requires 1.5 GB to 2.5 GB for the OS, SurfaceFlinger compositor, and GPU texture allocations. Allocating too much will trigger Android's Low Memory Killer (LMK).
