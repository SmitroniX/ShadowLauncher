Product & Feature Roadmap

Designed for Maximum Player Empowerment

Every screen is meticulously designed to solve Android gaming friction points.

📦

Version-Isolated Instances

Each Minecraft profile automatically provisions its own isolated subfolder (e.g. instances/1.20.4-Fabric/) with dedicated mods/, resourcepacks/, and saves/ folders. Zero mod collision.

☕

Smart Multi-JRE Auto-Selector

No more JVM crash codes. The launcher automatically assigns Java 21 for 1.20.5+, Java 17 for 1.17–1.20.4, and Java 8 for 1.12.2 and 1.8.9 PvP versions.

🧩

1-Click Modrinth / CurseForge Store

Search and install Sodium, Iris, Lithium, and PvP packs directly inside the launcher. The dependency resolver detects required API libraries and installs them seamlessly.

🕹️

Visual HUD Studio & Keymapping

Drag, scale, and align on-screen touch controls over a live game preview canvas. Switch between PvP Fast-Bridge, Casual Survival, and Physical Bluetooth Gamepad mapping with 1 tap.

⚡

Zero-Lag Telemetry & Battery Saver

Integrated live memory telemetry monitor, dynamic Aikar JVM GC tuning, and battery temperature management to prevent thermal throttling during intense multiplayer gameplay.

🌐

Integrated Community Hub

Directly wired to smitronix.dev documentation and Discord community for instant crash assistance and custom control share codes.

Designer Workflow

How to Import into Figma in 3 Minutes

Step-by-step instructions for working with these designs inside Figma.

1

Method A: Tokens Studio Plugin

1. Open Figma and install the Tokens Studio for Figma plugin.
2. Click Load Tokens and select shadow_launcher_tokens.json.
3. All colors, typography, and elevations will instantly populate your Figma Styles & Variables.

2

Method B: HTML to Figma (1-Click)

1. Install the Builder.io (HTML to Figma) plugin in Figma.
2. Enter this webpage's URL (or inspect any screen card).
3. The plugin will automatically convert all cards, auto-layout flexboxes, and text styles directly into editable Figma vector frames!

3

Method C: Direct Image Tracing

1. Download the high-res 16:9 and 9:16 mockups from the website/assets/designs/ folder.
2. Drag and drop directly into your Figma canvas.
3. Use Figma's Auto-Layout (Shift+A) to build responsive prototype components.
